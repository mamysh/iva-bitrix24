# Contributing

Спасибо за интерес к `iva-bitrix24`. Проект принимает исправления, тесты, улучшения
документации и предложения по новым строго ограниченным возможностям. Текущий MCP-контракт
предоставляет только чтение; изменение данных не принимается без отдельного архитектурного и
security review, явных подтверждений пользователя и отрицательных тестов.

## Перед началом

1. Для ошибки создайте issue с минимальным синтетическим примером.
2. Для новой возможности сначала опишите REST-метод, необходимые scope, возвращаемые поля и
   влияние на приватность.
3. Не прикладывайте webhook, домен частного портала, реальные ID, имена, задачи, скриншоты,
   логи или ответы API.

## Локальная проверка

Требуются Node.js 24 и npm:

```bash
npm ci
npm run check
```

Изменение MCP-контракта должно включать положительные и отрицательные тесты, обновление
README и при необходимости ADR. Новые REST-методы добавляются только в закрытый allowlist;
универсальный REST-call инструмент не принимается.

## Pull request

- Делайте изменение небольшим и самостоятельным.
- Используйте синтетические fixtures и адреса из зарезервированных example-доменов.
- Объясните влияние на разрешения, приватность и обратную совместимость.
- Убедитесь, что bundle пересобран и `npm run check` проходит.
- Подтвердите, что diff и история ветки не содержат секретов или рабочих данных.

Отправляя изменение, вы соглашаетесь лицензировать свой вклад на условиях MIT License этого
репозитория.
