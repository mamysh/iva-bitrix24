## Unreleased

## 0.3.0 — 2026-09-06

- Обновления из Telegram подтверждаются штатными кнопками Iva «⬆️ Обновить» и «Позже»:
  копировать SHA или фразу с телефона больше не требуется.
- Контур обновления ограничен записанным Git-источником этого плагина, полным SHA, зелёным
  GitHub Actions, свежим 15-минутным offer и одноразовым token. MCP не получает Telegram-токен.
- Фоновый worker запускается в отдельном user-systemd unit, переживает рестарт MCP, проверяет
  установленный SHA и `iva doctor`, а при отказе диагностики пытается вернуть прежнюю версию.
- Status различает успешное обновление, rollback, ошибку, зависшую очередь и результат,
  superseded более новым установленным SHA. Shell/systemd fallback из skill запрещён.
- Контракт чтения задач получил строгие ID и ISO-даты, стабильные названия статусов,
  приоритетов и оценок, безопасные имена участников и группы без дополнительных REST scopes.
- Добавлены однозначный `overdueOnly` с отметкой `asOf`, документированный фильтр
  `REAL_STATUS`, явные частичные результаты и безопасная нормализация ошибок Bitrix24.
- Проверка подключения больше не читает список задач, а пустой результат просроченных не
  дополняется догадками или ближайшими задачами.
- Production canary подтвердил кнопочный flow, фоновое обновление, последующий status,
  работоспособность MCP и диагностику Iva. Общее сообщение Iva об оборванном ходе после
  рестарта остаётся известным ограничением ядра и не определяет результат update-job.

## 0.2.0 — 2026-09-06

- Добавлены безопасная проверка обновления из записанного GitHub-источника, явное
  подтверждение точного SHA, фоновый systemd worker, статус, `iva doctor` и автоматическая
  попытка возврата предыдущего SHA при провале диагностики.
- Публичное описание проекта отделяет общую интеграцию Bitrix24 для Iva от read-only статуса
  текущего выпуска; синхронизированы README, package metadata и GitHub About/topics.
- Добавлен русскоязычный установщик одной командой: штатная установка через Iva, скрытый
  ввод и проверка webhook, атомарный env `0600`, явный trust, диагностика и переход в Telegram.
- Установщик и skill различают REST scope и права пользователя и дают точный путь исправления
  `insufficient_scope` для права «Задачи» без рекомендации включать доступ ко всему порталу.
- Репозиторий подготовлен к открытой разработке: MIT License, публичная документация,
  contribution/security policies и расширенный secret scan.
- Добавлено ограниченное read-only чтение истории задачи через `bitrix24_task_history`;
  используется существующий scope `task`, логин автора события не возвращается.
- Нормализованные задачи содержат безопасную ссылку `webUrl` без webhook-секрета.
- Список задач сохраняет метаданные пагинации Bitrix24 и возвращает безопасный `nextStart`.
- Skill запрещает обход MCP через shell, чтение env плагина и прямые вызовы webhook.
- Уточнены правила работы со статусами задач и экономного чтения деталей.
- Совместимость подтверждена на Iva 0.4.0.

## 0.1.0 — 2026-08-25

- Первый read-only контур для задач Bitrix24.
- Четыре MCP-инструмента: проверка подключения, список задач, чтение задачи и метаданные
  полей.
- Закрытый allowlist REST-методов, ограничение ответов, retry, timeout и redaction.
