# ADR-0013: необязательный общий API Panels для настроек Bitrix24

Статус: принято, 2026-10-09.

Panels предоставляет общий интерфейс кнопок и управления плагинами. Настройки
Bitrix24 должны оставаться внутри Bitrix24 и работать независимо от установки Panels.

Поставляем descriptor iva-panels/v2 и отдельную managed службу с приватным Unix
socket. Отдельный процесс не захватывает занятую MCP session и не конфликтует
с краткоживущими stdio-клиентами обычного меню. Служба не вызывает Bitrix REST.

Используем существующий SettingsStore и общую policy lock. Policy, revision и
квитанция подтверждения фиксируются одним atomic rename/fsync в settings.json.
Все изменения через старое меню сохраняют квитанции, но они скрыты от MCP-ответов.
Prepare/отмена используют отдельные приватные предложения; status чисто читающий.
CAS и TTL сохраняют защиту при нескольких интерфейсах. Старые версии strict reader
не совместимы с квитанциями после первого сохранения: откат требует миграции оператора.

Результат: generic Panels не содержит знания настроек Bitrix24; плагин работает без
Panels и сохраняет собственную бизнес-валидацию. Unix UID остаётся общей границей
доверия. Подтверждение Panels не является криптографической аттестацией человека;
граница доверия Bridge остаётся прежней. Другие бизнес-действия этим API не добавляются.
